Instructions

How to update this website.

A short guide for the HMXTECH team. Pages, publications, news and form submissions are all managed in the Statamic control panel, with no code needed.

Signing in

Go to /cp on this website and sign in with your staff account. Everything below is edited there and goes live as soon as you press Save. Ask the site administrator if you need an account or a password reset.

Home page

Open Collections → Pages → Home. The Hero Slider tab holds the three slides: photo, image description, eyebrow, headline and buttons. Use real, sharp project photos at least 2000 pixels wide. The Features tab holds the “What we do” cards.

Publications

Open Collections → Publications and press Create entry. Add the title, topic, a one or two sentence summary and the full link to the PDF. Drag papers in the list to change their order. Turn on Featured to show a paper in the large card at the top of the page.

News

Open Collections → News. Each item has a type, an optional date and organiser, a short summary and an optional link to a poster or PDF. New items appear in the order you set by dragging them in the list, so put the newest at the top.

Quote requests and sign-ups

Every quote request is emailed to info@hmxtech.co.tz and saved under Forms → Project Enquiry. News sign-ups are saved under Forms → Newsletter. You can export both as a spreadsheet from the same screen.

Company details and search

Open Globals → Settings to change the phone number, email, address, company description and the default text search engines show. Each page also has its own SEO title and description on the page itself.

Colours, type and components

The brand colours, type and components are documented in the Style guide. Changes to colours or layout are made by a developer in the website code, so the whole site stays consistent.
